모델 가격·성능

토큰당 가격이 싼 오픈웨이트 모델이 같은 일을 시켰을 때도 싼지를 네 가지 물음으로 확인합니다.

점수·과제당 비용 2026-11-20 · 지출 비중 2026-11-19 · 자체 서빙 원가 2026-11-20

GPU·메모리 가격AI 모델 가격·성능

점수와 과제당 비용은 Artificial Analysis 가 같은 과제로 잰 값이고 지출 비중은 OpenRouter 한 채널의 집계입니다. 프론티어, 배수, 자체 서빙 원가는 그 값으로 낸 계산입니다. 물음 아래의 굵은 한 줄은 그날 기록에서 계산한 답입니다. 매수·매도 권유가 아닙니다.

1. 토큰이 몰리는 곳에 돈도 몰리나 OpenRouter 집계 · 최근 30일 · 작업마다 상위 10개 모델만 이름이 나와 묶음의 몫은 하한입니다

지출의 몫은 미국 대형사 40.0% · 중국 17.3%, 토큰의 몫은 중국 51.4% · 미국 대형사 13.3%입니다.

2. 오픈웨이트는 프론티어만큼 해내나 지능 지수 · 모델 26개(오픈웨이트 10개) · 선은 더 싸면서 점수가 같거나 높은 모델이 없는 모델을 이은 것

오픈웨이트 최고 점수는 46.5점(Kimi K3.1 Pro), 전체 최고는 64.6점(Claude Fable 5.2)으로 18.1점 차이입니다. 50점 이상에는 오픈웨이트가 없습니다. 그 점수를 넘는 클로즈드가 처음 나온 지 31일 뒤에 나온 모델입니다.

3. 해내는 점수대에서는 더 싼가 그 점수 이상을 내는 모델 가운데 가장 싼 것끼리 · 과제당 달러(API 가격) · 로그 눈금 · 오른쪽 숫자는 오픈웨이트 ÷ 클로즈드

오픈웨이트가 닿는 기준선 4개 모두에서 오픈웨이트가 3.8~27배 비쌉니다. 가장 빠른 것끼리 견준 처리 시간도 4.2~13배 깁니다.

4. 직접 서빙하면 뒤집히나 Kimi K3.1 Pro(46.5점)를 GB300 NVL72에서 · $2.31/시간 · 사용자당 100토큰/초 · 기준일 2026-11-20의 계산 기록

가동률 100%에서 과제당 원가는 $0.56입니다. 같은 모델의 API($3.68)보다는 가동률 15%부터 쌉니다. 점수가 더 높은 클로즈드 가운데 가장 싼 GPT-6.1 Terra(51.3점, API $0.96)와 같아지는 가동률은 58%입니다.

자체 서빙 원가가 그 모델의 API 비용과 같아지는 가동률입니다. 막대가 길수록 높은 가동률을 채워야 자체 서빙이 쌉니다. 점수가 더 높은 클로즈드 모델과 대상 모델 자신의 API 만 실었습니다.

이 답이 바뀌고 있나 날마다 쌓는 기록 · 프론티어는 값이 바뀐 날만 점이 찍힙니다

같은 점수에서의 비용 배수와 묶음별 지출 비중을 2026-11-19부터 쌓고 있습니다. 기록이 이틀 이상이 되면 여기에 추이 그림이 나옵니다.

가정

  • Kimi K3.1 Pro 의 서빙 효율이 같은 크기(2.8T)의 Kimi K3 와 같다. K3.1 Pro 의 측정값은 찾지 못했다.
  • 벤치마크의 토큰 구성이 Artificial Analysis 과제의 구성(캐시 읽기 95.5%)과 비슷하다.
  • FP4 로 서빙해도 Artificial Analysis 가 잰 점수가 유지된다.
  • 과제당 토큰 수는 Artificial Analysis 의 과제당 비용 내역을 공식 단가(입력 2달러, 출력 10달러, 캐시 읽기 0.2달러, 100만 토큰당)로 나눈 값이다.

한계

  • 처리량 출처의 화면에는 SemiAnalysis 와 무관한 비공식 배포이며 자료가 수정됐거나 오래됐을 수 있다는 안내가 붙어 있고, 같은 조건의 처리량이 화면마다 다르게 나온다(사용자당 50토큰/초에서 8,601 과 25,544).
  • 시간당 2.31달러는 하이퍼스케일러 규모의 소유 원가다. 일반 기업의 원가는 더 높고, 업무 시간에만 쓰는 사내 수요는 가동률이 낮게 나오기 쉽다.
  • 손으로 넣은 계산 기록이다. 날마다 갱신되지 않으며 기준일의 값이다.
