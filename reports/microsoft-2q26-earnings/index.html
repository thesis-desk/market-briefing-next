Microsoft 2Q26 실적발표 : OpenAI가 부풀린 RPO, 배분에 묶인 Azure

해석 매출·영업이익·EPS는 회사 예상을 넘었다. 다만 Azure 성장률(고정환율)은 2Q 38%에서 3Q26 37~38%로 소폭 낮게 안내됐고, 상업 RPO 6,250억 달러의 약 45%가 OpenAI 몫이다. 이번 분기를 읽는 열쇠는 성장률 자체보다 GPU를 어디에 배분했는지, 그리고 수주가 한 고객에 얼마나 몰렸는지다.

한 문장 결론

해석

매출 813억 달러(+17%), 영업이익률 47%, EPS 4.14달러(OpenAI 영향 조정 기준 +24%)로 회사 예상을 넘었다. 같은 분기에 CapEx 375억 달러, FCF 59억 달러, Azure 감속 안내가 함께 나왔다. 직전 분기와 달라진 점은 셋이다.

  • 수주 잔고가 커졌고, 한 고객에 쏠렸다. 상업 RPO는 6,250억 달러(+110%)이고 그중 약 45%가 OpenAI다. 가중평균 만기는 약 2년에서 2.5년으로 늘었다.
  • Azure 가이던스의 뜻이 바뀌었다. 경영진은 Azure 성장률을 수요 지표가 아니라 ‘배분된 용량’ 가이던스로 읽으라고 했다. 1·2분기에 새로 들어온 GPU를 모두 Azure에 넣었다면 40%를 넘었을 것이라고 했다.
  • OpenAI 지분법 처리가 바뀌었다. OpenAI 자본 재편 이후 지분법 손익을 순자산 변동분 기준으로 인식한다. 이 때문에 GAAP 영업외손익이 100억 달러가 됐고, 보고 이익과 조정 이익의 차이가 커졌다.

답변Amy Hood · CFO

출처 2 · EPS 예상 대비 실제

사실

회사 자체 예상 대비: 매출·영업이익·EPS는 예상을 넘었다. Azure는 약간 상회, Microsoft Cloud 매출총이익률도 약간 상회했다. M365 Commercial Products, 온프레미스 서버, Windows OEM은 예상을 넘었다. 검색 광고는 약간 하회, Xbox 콘텐츠·서비스는 하회했다. OpenAI를 뺀 영업외손익은 예상보다 낮았다.

출처 1 · 준비 발언 — Amy Hood

계산

3Q26 가이던스가 함축하는 영업이익은 약 359억~373억 달러(중앙 약 366억 달러)이고, 영업이익률은 약 44.5~45.6%(중앙 약 45.1%)다. 2Q26의 47%보다 약 2%p 낮다. 같은 중앙값으로 계산한 매출총이익률은 약 67.1%로 2Q26의 68%보다 낮다. 매출원가 증가율(22~23%)이 매출 증가율(15~17%)을 웃돈다는 안내와 맞는 값이다.

식: 영업이익 = 매출 − 매출원가 − 영업비용 (하단: 806.5−268.5−179, 상단: 817.5−266.5−178); 영업이익률 = 영업이익 ÷ 매출

상업 RPO 가운데 OpenAI 몫은 1년 사이 약 240억~290억 달러에서 약 2,810억 달러로 10배 안팎 늘어난 것으로 추정된다. RPO 증가분 약 3,270억 달러 중 약 2,500억 달러(약 4분의 3)가 OpenAI에서 나왔다. 비중(약 45%)과 금액(약 3,500억 달러)이 모두 ‘약’으로 제시돼 결과는 근사치다.

설명
  • 보고 부문은 셋이다. Productivity and Business Processes(M365, LinkedIn, Dynamics), Intelligent Cloud(Azure, 온프레미스 서버), More Personal Computing(Windows, 검색 광고, 게임)이다. Microsoft Cloud는 부문을 가로지르는 회사 집계 지표다. 이 콜에서는 구성을 정의하지 않았다.
  • Azure 성장률(고정환율)은 회사가 직접 ‘KPI’라고 부르는 지표다. 이번 콜에서 CFO는 이 값을 ‘배분된 용량’ 가이던스로 읽으라고 했다. GPU를 쓰는 순서는 자체 서비스(M365 Copilot, GitHub Copilot)가 먼저이고, 다음이 R&D 인력, 남는 몫이 Azure 외부 고객이다. 따라서 Azure 성장률은 수요보다 공급과 배분 결정을 더 반영한다.
  • 상업 RPO는 충당금을 뺀 순액으로 보고된다. 이번 콜에서는 OpenAI 비중(약 45%)과 그 밖 잔고의 성장률(+28%)을 따로 밝혔다. 가중평균 만기는 M365·BizApps 같은 3년 계약과 그보다 긴 Azure 계약이 섞인 값이다.
  • CapEx는 단기 자산과 장기 자산으로 나뉜다. 단기 자산은 GPU·CPU 등이고 이번 분기 약 3분의 2였다. 장기 자산은 데이터센터 부지 등으로 15년 이상 수익화된다. 상당 부분이 금융리스로 들어오므로 금융리스 비중이 낮은 분기에는 현금 CapEx가 늘고 FCF가 줄어든다. 서버는 6년에 걸쳐 감가상각한다.
  • OpenAI 투자는 지분법으로 처리한다. OpenAI 자본 재편 이후에는 OpenAI 손익 대신 OpenAI 순자산 변동분에 대한 지분을 영업외손익으로 인식한다. 회사는 EPS 증가율과 영업외손익 가이던스를 이 영향을 뺀 기준으로 제시한다.
  • 경영진이 최적화한다고 밝힌 지표는 ‘와트당·달러당 토큰(tokens per watt per dollar)’이다. 가동률을 올리고 실리콘·시스템·소프트웨어로 TCO를 낮추는 것을 뜻한다.

Ignite에서 프런티어 전환 이야기를 많이 들었습니다. 기업들이 이 전환에 나서는 흐름을 어떻게 보는지, 프런티어 기업이 되면서 Microsoft 지출이 얼마나 늘 수 있다고 보는지 설명해 주십시오.

ASatya Nadella · 회장·CEO

세 주요 제품군인 M365, 보안, GitHub 전반의 채택이 보입니다. 과거에도 Entra나 Defender처럼 세 영역에 걸쳐 효과가 복리로 쌓였습니다. 이제는 Work IQ가 그 역할을 합니다. Microsoft를 쓰는 회사에서 가장 중요한 데이터베이스는 Microsoft 365 아래의 데이터입니다. 누가 사람이고 어떤 관계이며 무슨 프로젝트와 산출물·커뮤니케이션이 있는지라는 암묵적 정보를 담고 있기 때문입니다.

Work IQ를 MCP 서버로 쓰고 GitHub 저장소와 연결해 ‘지난달 Teams 설계 회의를 보고 내 저장소가 그것을 반영하는지 알려 달라’고 할 수 있습니다. 이 에이전트 계층이 기업을 바꾸고 있습니다. 그 위에서 기업들은 고객 서비스·마케팅·재무를 어떻게 바꿀지 고민하며 Fabric, Foundry, GitHub 도구, 로코드·노코드 도구로 자체 에이전트를 만듭니다. M365 Copilot, GitHub Copilot, Security Copilot이 함께 데이터와 배포의 효과를 복리로 키우는 것이 지금 가장 큰 변화입니다.

Azure의 CPU 측면과 클라우드 이전

QRaimo Lenschow · Barclays 애널리스트

(IR의 확인 요청 뒤 다시 정리한 질문) Azure의 CPU 측면에서 운영상 변화가 있었는데, 무엇을 봤는지 궁금합니다. 현장에서는 제대로 된 AI를 하려면 클라우드에 있어야 한다는 인식이 퍼진다고 듣는데, 그것이 클라우드 이전을 밀어 올리고 있습니까?

ASatya Nadella · 회장·CEO

준비 발언에서도 말했듯 AI 워크로드를 가속기 연산으로만 생각하면 안 됩니다. 에이전트는 도구를 쓰면서 컨테이너를 띄우고, 그것은 일반 연산에서 돕니다. 그래서 플릿을 지을 때도 비율로 생각합니다. AI 학습 작업도 연산 가까이에 상당한 연산과 스토리지가 필요하고, 에이전트 모드 추론도 에이전트에게 컴퓨터, 즉 연산·스토리지 자원을 할당해야 합니다. GPU가 필요한 것이 아니라 컴퓨터가 필요합니다.

클라우드 이전도 계속되고 있습니다. 최신 SQL Server가 Azure에서 IaaS로 늘고 있다는 수치를 소개했습니다. 고객이 기존 워크로드와 새 워크로드를 가져오면 배포하는 지역에 모든 인프라 요소가 필요하기 때문에, 상업 클라우드를 AI 클라우드와 균형 있게 유지해야 합니다.

긍정적이었던 내용

해석

이 사이트에 직전 분기 리포트가 없어, 직전 분기 값은 원문이 언급한 것만 적는다. 이어받을 ‘다음 분기에 확인할 지표’도 없다.

  • OpenAI를 뺀 수주 잔고가 고르게 늘었다. 직전 분기: RPO 만기 약 2년(그 밖의 값은 원문에 없음). 이번: RPO 6,250억 달러 중 OpenAI 외 약 3,500억 달러가 +28%였고 고객군·산업·지역별로 고르게 늘었다. 12개월 내 인식분도 +39%다. 의미: 집중 우려와 별개로 기저 수요의 폭이 확인됐다. 12개월 내 인식분 +39%는 향후 1년 매출 가시성을 높인다.
  • M365 Copilot 수익화가 숫자로 들어오기 시작했다. 직전 분기: 원문에 비교치 없음. 이번: 유료 좌석 1,500만, 좌석 순증 +160% 이상으로 사상 최대이고 전분기 대비 증가가 빨라졌다. M365 Commercial Cloud는 Copilot 기여를 업고 +17%(고정환율 +14%)였고, 3Q 가이던스도 13~14%로 성장률 유지다. 의미: 좌석 4.5억 개 이상의 기반 위에서 ARPU를 끌어올리는 경로가 작동하고 있다. 자체 서비스에 GPU를 먼저 배분한다는 설명에도 근거가 된다.
  • AI 투자 속에서도 이익률을 지켰다. 직전 분기: 원문에 수치 없음. 이번: 영업이익률은 47%로 전년 대비 상승했고 예상을 넘었다. Microsoft Cloud 매출총이익률은 67%로 예상을 약간 넘었다. FY26 영업이익률은 이제 소폭 상승으로 본다. 의미: AI 인프라 비용 증가를 효율 개선과 영업 레버리지로 흡수하고 있다. 다만 FY26 상향에는 메모리 인상 전 선구매로 늘어난 고마진 매출이 섞여 있다(부정적 내용 참고).
  • 같은 하드웨어에서 더 많이 뽑아내고 있다. 이번: OpenAI 추론 처리량 50% 향상, 공용 플릿 효율로 일부 용량을 Azure에 재배분해 Azure가 예상을 약간 넘었다. Maia 200은 TCO 30% 이상 개선이다. 의미: 공급이 제약된 동안 효율이 곧 매출이라는 점이 이번 분기 Azure 숫자에 직접 나타났다.
  • 현금 창출력이 강했다. 이번: 영업현금흐름 358억 달러(+60%), 주주환원 127억 달러(+32%). 의미: FCF가 59억 달러로 줄어든 것은 현금 창출 약화가 아니라 금융리스 비중에 따른 CapEx의 현금화 시점 문제다.

부정적이었던 내용

해석
  • Azure 감속 안내. 직전 분기: 원문에 수치 없음. 이번: 2Q 39%(고정환율 38%), 3Q 가이던스 37~38%(고정환율)로 고정환율 기준 0~1%p 낮다. 회사는 전년 3·4분기에 성장률이 크게 가속한 높은 비교 기저를 함께 들었다. 수요가 공급을 넘는다고 하면서도 감속을 안내했다. 의미: 원인은 수요보다 배분·용량 인도 시점과 비교 기저에 있다. 다만 자체 서비스와 R&D가 계속 GPU를 먼저 가져가는 한 외부 클라우드 성장률은 경영진 재량에 묶인다.
  • OpenAI 집중. 이번: RPO의 약 45%가 OpenAI이고, 1년 사이 OpenAI 몫이 10배 안팎 늘었다(숫자 요약의 계산). 회사도 예약·RPO 성장률에 분기 변동이 생긴다고 예고했다. 의미: RPO 증가분의 약 4분의 3이 한 고객에서 나왔다. 그 계약의 지속성에 대한 질문에는 직접 답이 없었다.
  • CapEx 부담과 FCF. 이번: CapEx 375억 달러, FCF 59억 달러로 전분기 대비 감소. Microsoft Cloud 매출총이익률은 67%에서 3Q 약 65%로 안내됐다. 3Q 가이던스가 함축하는 영업이익률은 약 45%로 2Q의 47%보다 낮다. 의미: 감가상각이 매출총이익률을 누르는 흐름이 다음 분기에도 이어진다.
  • 소비자·MPC 부진. 이번: 게임 −9%, Xbox 콘텐츠·서비스는 예상 하회이고 게임 사업 손상차손이 있었다. 검색 광고는 실행상 문제로 약간 하회했다. 3Q MPC 가이던스는 123억~128억 달러로 2Q 143억 달러보다 낮다. Windows OEM은 약 −10%로 안내됐다.
  • 메모리 가격 상승의 양면. 이번 분기 Windows OEM과 온프레미스 서버의 예상 상회에는 메모리 가격 인상 전 선구매가 섞였다. 다음 분기에는 되돌림이 예상되고 PC 시장 전망 범위도 평소보다 넓다. 같은 요인이 CapEx를 밀어 올린다. 그 영향은 6년 감가상각을 거쳐 Microsoft Cloud 매출총이익률에 서서히 쌓인다.

읽을 때 걸러 들을 점

해석
  • 제3자 전사본이다. 모델명(‘GPT-5 too’)과 3Q 예약 가이던스 문구(‘ex-pre base’) 등 받아 적기가 불분명한 곳이 있다. 이 부분은 해석에 쓰지 않았다.
  • OpenAI 회계 효과로 보고 이익과 조정 이익이 갈린다. GAAP 영업외손익 100억 달러는 OpenAI 순자산 변동분에 대한 지분 이익이다. EPS 증가율(+24%)은 OpenAI 영향을 뺀 기준으로 제시됐다. GAAP EPS와 조정 EPS의 차이 금액은 콜에서 말하지 않았다. 앞으로도 OpenAI 순자산 변동이 GAAP 이익을 흔든다.
  • ‘CapEx’ 375억 달러와 현금 숫자는 기준이 다르다. 유형자산 현금 지출 299억 달러와 금융리스 67억 달러는 다른 기준의 숫자다. 375억 달러에 금융리스가 어떻게 포함되는지는 콜에서 정의하지 않았다.
  • ‘Azure를 전부 줬다면 40% 초과’는 반사실 가정이다. 경영진만 검증할 수 있는 수치다. 감속 안내를 배분 문제로 돌릴 동기가 있는 자리에서 나온 말이다.
  • 정의 없이 쓴 숫자가 있다. ‘수십 년 걸린 최대 사업보다 큰 AI 사업’에는 규모 수치가 없다. ‘수요가 공급을 넘는다’도 정량화하지 않았다.
  • 계약이 내용연수를 덮는다는 설명의 근거가 공개되지 않았다. ‘GPU 대부분이 내용연수 대부분에 대해 이미 계약됐다’는 설명을 확인할 수치(비율·계약 기간)는 없다.
  • RPO 수치는 근사치다. RPO는 충당금 차감 순액이고, OpenAI 비중은 ‘약 45%’, 비OpenAI 금액은 ‘약 3,500억 달러’로 둘 다 근사치다.
  • 거의 1GW의 기준이 불명이다. 회사 표현은 ‘total capacity’로 IT 기준인지 수전 기준인지 밝히지 않았다.
  • FY26 영업이익률 상향에는 일회성이 섞였다. 근거로 든 ‘Windows OEM·상업용 온프레미스의 높은 매출 비중’에는 메모리 인상 전 선구매라는 일회성이 포함돼 있다.
  • 직접 답하지 않은 질문: Maia의 매출총이익률 효과(CFO 미답), 향후 용량 추가 규모, 프런티어 기업의 지출 확대 폭, OpenAI 계약의 지속성·조건, Azure CPU 측면의 운영상 변화.

다음 분기에 확인할 지표

해석
  • Azure 성장률(고정환율). 가이던스는 37~38%다. 상단을 넘거나 40%대로 돌아오면 ‘배분 문제’ 설명이 맞았다는 근거가 된다. 37% 아래면 수요 둔화 해석이 힘을 얻는다.
  • Microsoft Cloud 매출총이익률. 가이던스는 약 65%다. 65%를 의미 있게 밑돌면 AI 감가상각과 메모리 가격 부담이 예상보다 빠르다는 뜻이다.
  • 상업 RPO와 OpenAI 비중. 2Q는 6,250억 달러, 약 45%, 비OpenAI +28%였다. 비OpenAI 성장률이 20%대를 유지하는지가 기저 수요의 기준이다. OpenAI 비중이 더 오르면 집중 위험이 커진다.
  • CapEx와 FCF. 3Q CapEx는 전분기 대비 감소, 단기 자산 비중은 비슷하게 안내됐다. 감소하지 않거나 FCF가 계속 줄면 투자 부담 판단을 높인다.
  • M365 Copilot 유료 좌석과 M365 Commercial Cloud 성장률. 2Q는 1,500만 좌석이고 3Q 가이던스는 13~14%(고정환율)다. 좌석 증가가 계속 빨라지는지가 자체 서비스 우선 배분의 성과 지표다.
  • 분기 용량 추가량. 2Q는 거의 1GW(기준 불명)였다. 같은 수준 이상이면 Azure 공급 제약이 풀리는 속도를 가늠할 수 있다.
  • Windows OEM과 온프레미스 서버. 가이던스는 각각 약 −10%, 한 자릿수 초반 감소다. 메모리 가격에 따른 되돌림 폭을 확인한다.
  • Xbox 콘텐츠·서비스. 가이던스는 한 자릿수 중반 감소다. 추가 손상이나 더 큰 감소가 있는지 본다.

이 리포트에 나온 용량 값

IT 용량이 기본입니다. “수전”은 IT 용량 없이 계통에서 받는 전력만 공개된 값이고, “기준 불명”은 회사가 기준을 밝히지 않은 값입니다.

해석
  • 메시지별 확신. ‘수요가 공급을 넘고 Azure 감속은 배분 탓’에는 확신 중간이다. 반사실 수치뿐이지만, 이후 3Q26 매출이 가이던스 상단을 넘은 점은 이 설명과 맞는다. ‘GPU는 내용연수 전체에 대해 팔렸다’에는 확신 낮음~중간이다. 비율·계약 조건이 공개되지 않았다. ‘비OpenAI 잔고의 폭넓은 성장’에는 확신 높음이다. +28%가 고객군·산업·지역에 고르게 분포했다.
  • 실적 추정의 방향. 2Q26 콜 시점에는 감가상각 증가로 마진 하향 위험이 있었다. 이후 세 분기 연속 EPS가 예상을 3.6~11.8% 넘었다. 컨센서스는 FY27 EPS 성장 약 16%, FY28 약 21%를 담고 있다. 추정의 방향은 상향 쪽이 우세했던 것으로 보인다(확신 중간). Azure 성장률과 Microsoft Cloud 매출총이익률의 후속 값은 이 자료에 없어 마진 경로는 확인하지 못했다.
  • 밸류에이션의 전제. FY27 약 25배, FY28 약 21배는 컨센서스의 이익 고성장이 실현된다는 전제다. 그 전제가 흔들리는 길은 두 가지다. 하나는 OpenAI 몫(RPO의 약 45%)의 실행이 지연되거나 조건이 바뀌는 경우, 다른 하나는 CapEx 증가가 매출총이익률을 65% 아래로 누르는 경우다.
  • 주주에게만 해당하는 위험. OpenAI 지분법 이익이 GAAP EPS를 크게 흔들어 보고 이익 기준 배수가 왜곡될 수 있다. 2Q26 발표 직후 시간외 하락(Q&A 1의 애널리스트 언급)처럼 CapEx·Azure 수치에 대한 주가 반응이 실적과 따로 움직일 수 있다. 희석 관련 언급은 원문에 없다.
  • 종합 판단 — MSFT: 약한 호재(확신 중간). 근거는 세 가지다. 비OpenAI 수주의 고른 성장, Copilot 수익화 가속, 이후 세 분기의 EPS 상회가 그것이다. 평균 목표주가가 종가보다 약 28% 높은 것은 시장이 아직 이익 성장을 다 반영하지 않았다고 본다는 뜻이지만, 목표주가는 애널리스트 의견일 뿐이다. 판정을 바꾸는 조건: Azure 성장률이 30%대 중반 아래로 떨어지거나, Microsoft Cloud 매출총이익률이 65%를 뚜렷이 밑돌거나, OpenAI 계약에 변경이 생기면 중립 이하로 낮춘다. 용량 확대와 함께 Azure가 40%대로 재가속하면 강도를 높인다.
  • 다른 종목. 콜은 NVIDIA·AMD를 플릿 공급사로, 메모리 가격 상승을 비용 요인으로 언급했다. 그러나 Maia 비중이나 공급사별 구매 규모 같은 정량 근거가 없어 이 공급사들과 메모리 업체는 판정하지 않는다. OpenAI·Anthropic은 상장사가 아니다.
