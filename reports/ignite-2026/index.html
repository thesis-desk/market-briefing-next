핵심

해석

이번 Ignite로 바꿔야 할 판단은 마이크로소프트가 AI의 원가와 계량기를 직접 쥐려 한다는 점이다. 일상 작업의 토큰은 자사 MAI 모델과 자사 라우터로, 과금은 좌석 위에 사용량을 얹는 이중 구조로, 에이전트의 실행 환경은 GPU 밖(CPU·클라우드 PC·로컬 PC)으로 넓혔다. 다만 성능·가격 수치는 모두 회사 측정이고, 매출·처리 비중·자체 칩 물량은 하나도 나오지 않았다.

  • 마이크로소프트는 Copilot의 일상 토큰을 자사 MAI 모델로 옮길 수단을 갖췄다 — 단 가격 비교는 회사 측정이고, 보도로는 50% 출시 할인가 기준이다 (확신: 방향 높음, 크기 낮음)
  • Copilot의 과금 축이 좌석에서 사용량으로 넓어졌다 — 계량 대상은 늘었지만 매출 규모는 하나도 공개되지 않았다 (확신 중간)
  • 에이전트의 일이 GPU 밖으로 퍼진다 — 마이크로소프트는 CPU·클라우드 PC·로컬 PC를 에이전트 실행처로 묶었다 (확신: 방향 중간, 크기 낮음)
  • 마이아의 전성비 주장과 달리, 이번 행사에서 실제로 돌고 있다고 확인된 대규모 연산은 엔비디아다 (확신 중간)

출처 12 · Introduction; The 4 steps of "Your IQ. Your agents. Your weights."

해석

핵심은 모델 하나의 점수가 아니라 라우터를 마이크로소프트가 쥐었다는 점이다. Copilot 질의의 90% 이상이 Auto를 거치고, 그 안에서 어떤 모델에 얼마의 추론을 쓸지 자사 Decision-1.1이 정한다. 일상 코딩·문서·보안 작업에 쓸 만한 자사 모델(Code 2, Code 2 Flash, Cyber 2 Flash)이 생겼으니, 회사는 대량 작업을 외부 프론티어 모델에서 자사 모델로 돌릴 수 있게 됐다. 프론티어 모델은 Code 2가 다루지 않는 가장 어려운 작업에만 남는다.

가격 우위는 할인을 걷어 내면 줄어든다. 50% 출시 할인이 비교 수치 전체에 걸린 것이라면 정가 기준으로 Code 2는 Opus 5.5의 약 10%, GPT-6.1 Sol의 약 80%다. Anthropic 대비 우위는 여전히 크지만 OpenAI 대비 우위는 대부분 사라진다. 할인이 어느 비교에 걸렸는지는 원문에서 분명하지 않다.

크기와 시점은 가늠할 수 없다. Copilot·GitHub Copilot 토큰 가운데 MAI가 처리하는 비중, MAI 모델의 내부 사용량, 정가 시점이 모두 공개되지 않았다. 방향에 대한 확신은 높고 크기에 대한 확신은 낮다.

마이크로소프트에는 호재다. 대량 작업을 자사 모델로 돌리는 만큼 Copilot의 추론 원가와 외부 랩에 내는 비용이 줄고, 외부 랩과의 협상력이 커진다. 고객의 토큰 비용 불만을 자사 제품의 판매 논리로 바꾼 셈이다.

OpenAI·Anthropic에는 대량 작업 구간에서 악재다. 마이크로소프트 제품 안의 일상 작업 물량이 자사 모델로 빠질 수 있다. 다만 Copilot은 직원이 OpenAI·Anthropic 모델을 직접 고르는 선택지를 남겼고, Work IQ·Fabric IQ도 두 회사 쪽으로 연결을 넓힌다(s1, s7). 고급 작업과 유통 경로는 남는다.

엔비디아에는 엇갈린다. 작업당 연산은 줄지만, 회사가 내세운 그림은 "싼 모델로 에이전트를 24시간 돌리는" 물량 확대다.

이 주장이 틀리는 경우: 첫째, 벤치마크를 회사가 골랐고 독립 측정이 아직 없다. Foundry에서 고객이 직접 측정한 값이 회사 수치에 크게 못 미치면 전제가 무너진다. 둘째, 할인이 끝난 뒤 정가가 공개되지 않았다. 50% 출시 할인 적용도 ZDNET(s15) 한 곳만 전한 회사 설명이다. 셋째, Decision-1.1의 기반이 구글 Gemma라 '자사 모델'의 범위가 생각보다 좁을 수 있다. 넷째, 사용자가 수동으로 프론티어 모델을 계속 고르면 라우팅 효과가 작아진다. AT&T 사례와 토큰 비용 발언은 개인 블로그(s12)를 거쳐 들어온 것이다.

Copilot의 과금 축이 좌석에서 사용량으로 넓어졌다 — 계량 대상은 늘었지만 매출 규모는 하나도 공개되지 않았다

사실
  • Agent 365 Cost Management가 사용량 과금 AI 서비스를 한곳에서 보고 통제한다. 대상은 Copilot Cowork, Copilot Code, GitHub Copilot CLI, Copilot Studio, Copilot Managed Runtime, Autopilot, Work IQ API다. 지출 정책·한도·알림은 프리뷰이고, 12월에 타사 에이전트의 가치 분석으로 넓힌다.
  • Today Brief(아침 브리핑)는 Microsoft 365 Copilot 라이선스에 포함되지만, 하루 중 반복 갱신하는 Today Feed는 Copilot 크레딧이 필요하다.
  • Windows 365 for Agents가 Copilot 크레딧 과금 대상이 됐다.
  • Microsoft IQ는 새 SKU나 구독 없이 기존 제품 위에 얹는다.
  • 기본 에이전트 사용 지표는 Agent 365 라이선스와 관계없이 제공하지만, 보안·거버넌스 전체 기능에는 Agent 365 또는 ME7 라이선스가 필요하다. Viva Insights는 Agent 365 라이선스 요건을 없애되 Copilot 라이선스 50개 이상 요건은 유지한다.

출처 17 · Microsoft 365 and Copilot: What changes for users

해석

구조는 이렇다. 가시성(기본 지표)은 무료로 풀어 에이전트를 많이 등록하게 하고, 실제로 일하는 서비스(Cowork·Code·Autopilot·Windows 365 for Agents·Today Feed)에는 크레딧 계량기를 붙인다. 그리고 IT 밖에 있는 AI 예산을 잡도록 비용과 '완료한 업무'를 연결하는 분석 도구를 현업 리더에게 판다. t1의 자사 모델은 이 구조에서 원가를 맡는다. 원가가 낮으니 Claude·ChatGPT보다 싸게 팔면서도 사용량 매출을 키울 수 있다.

전에는 Copilot을 좌석 수로만 셌다면, 이제는 좌석에 더해 크레딧 소비가 매출 동인이 된다. 그러나 이번 행사에서 Copilot 좌석 수, 크레딧 매출, 사용량 성장률은 하나도 공개되지 않았다. 포춘 500 침투율('80% 가까이')만으로는 매출 크기를 가늠할 수 없다. 시점은 Copilot Code GA(12월)와 Cost Management 확대(12월) 뒤 몇 분기다. 확신은 중간이다.

마이크로소프트에는 호재다. 에이전트 수(5,000만 개 이상)가 매출로 이어지는 경로가 생겼다. 반면 Anthropic·OpenAI의 기업용 구독은 마이크로소프트가 직접 가격을 비교해 공격하는 대상이 됐다. 회사가 '기능을 구독 쪽으로 옮기겠다'고 한 것은 고객에게는 좋지만, 마이크로소프트에게는 작업당 매출이 줄 위험이기도 하다.

이 주장이 틀리는 경우: 지출 한도·알림 기능은 고객이 소비를 억제하는 도구이기도 하다. 고객이 한도를 낮게 걸면 계량 매출은 작게 남는다. GigaOm 비교의 조건과 의뢰 관계는 원문에 없다. 'assisted hours'는 ROI가 아니어서, 현업 예산을 끌어오는 근거로는 약할 수 있다. 포춘 500 수치도 블로그(s7)는 '80% 가까이', 세션 발언(s8)은 '80% 이상'으로 서로 다르다.

에이전트의 일이 GPU 밖으로 퍼진다 — 마이크로소프트는 CPU·클라우드 PC·로컬 PC를 에이전트 실행처로 묶었다

사실
  • Azure Cobalt 200 VM을 GA했다. 에이전트가 일의 상당 부분을 모델 밖 범용 CPU에서 하고 임시 작업 공간을 계속 띄우기 때문에 CPU 속도가 작업 속도를 정한다는 것이 설계 근거다. Cobalt 100 대비 CPU 성능이 최대 50% 높고, 연말까지 24개 리전에 배치한다(s12는 23개로 적었다).
  • Windows 365 for Agents는 API가 없는 레거시 업무 앱을 다룰 수 있도록 에이전트에게 화면을 조작하는 클라우드 PC를 준다. 상시 켜 두는 영구 클라우드 PC(프리뷰)를 지원하고, Copilot Studio에서 컴퓨터 사용 도구로 제공된다. Foundry MCP 연동은 내년 초 프리뷰다.
  • Windows 365 클라우드 PC는 최대 32 vCPU와 GPU를 붙여 로컬 AI 모델을 돌릴 수 있다(GA).
  • Windows Server 2028은 기업 데이터 가까이에서 AI 추론을 돌리도록 AMD MI350P와 엔비디아 GB300 Grace Blackwell Ultra Desktop Superchip을 지원한다(하이브리드 AI 기능은 제한된 조기 접근).

해석

발표들을 나란히 놓으면 에이전트 한 건의 비용이 두 덩어리로 보인다. 모델 토큰(GPU)과 실행 환경(CPU 샌드박스, 화면을 조작하는 클라우드 PC, 로컬 PC)이다. 마이크로소프트는 두 번째 덩어리를 따로 설계했다. 에이전트용 Arm CPU(Cobalt 200), 에이전트 전용 클라우드 PC(크레딧 과금), 격리 컨테이너(MXC), 로컬 모델로 일을 넘기는 라우팅(하이브리드 인텔리전스. Copilot Fusion의 로컬 라우팅은 보도로만 확인)이다. 로컬로 넘긴 추론은 마이크로소프트의 원가에서 고객 하드웨어로 옮겨 간다. t1과 같은 방향의 원가 전략이다.

AI 연산 수요를 GPU 대수로만 보던 판단에, 에이전트 수에 비례하는 CPU·클라우드 PC 수요가 더해진다. 크기는 가늠할 수 없다. RTX Spark 가격과 물량, Windows 365 for Agents 단가, Cobalt 200 배치 규모, 인텔 계약 규모가 모두 없다. 하이브리드 기능은 대부분 프리뷰다. 방향에 대한 확신은 중간, 크기에 대한 확신은 낮다.

마이크로소프트에는 호재다. 실행 환경에도 크레딧 계량기를 붙였다. 엔비디아는 RTX Spark로 Windows on Arm PC에 들어간 것이 새 판매처다(소폭 호재). 델은 RTX Spark 데스크톱의 판매사다. AMD는 MI350P가 Windows Server 2028에 들어갔고, Ryzen AI Max가 Copilot Fusion의 로컬 경로에 들어갔다는 보도가 있다. 인텔은 Xeon 장기 공급을 보도로만 확인했다. Cobalt 200이 Arm 기반이라 x86 서버 CPU에는 Azure 안에서 대체 압력이 생긴다. 다만 인텔 계약 보도가 그 압력과 엇갈린다.

이 주장이 틀리는 경우: 클라우드 PC로 화면을 조작하는 에이전트는 API가 없는 레거시 앱을 위한 차선책이다. API·MCP 연동이 빨리 퍼지면 이 수요는 작게 남는다. 주문 처리 60% 단축은 회사 내부 사례 하나다. 하이브리드 인텔리전스는 제공 시점이 없다. Copilot Fusion의 로컬 라우팅(RTX Spark·Ryzen AI Max)은 개인 블로그 정리(s12)에만 있다. 인텔 계약은 언론 보도 하나에만 있다.

마이아의 전성비 주장과 달리, 이번 행사에서 실제로 돌고 있다고 확인된 대규모 연산은 엔비디아다

해석

t1의 MAI 모델은 엔비디아를 덜 쓰는 이야기로 읽히기 쉽다. 그러나 이번 행사 자료로 보면 Microsoft AI는 사후학습 중 강화학습 롤아웃 추론을 대규모 엔비디아 GPU 플릿 위에서 Dynamo로 조율하고, 새로 가동이 확인된 랙 규모 시스템도 Vera Rubin NVL72다. 마이아는 전성비 주장만 있다. Maia 300은 발표 단계이고, Maia 200은 비교 기준을 밝히지 않았다. 둘 다 배치 물량, 고객 제공 여부, 시점이 없다.

그래서 이번 행사로 마이크로소프트 안의 엔비디아 비중에 대한 판단을 바꿀 근거는 없다. 장기적으로 추론을 자체 칩으로 옮기려는 의도는 분명해졌다. 크기는 가늠할 수 없고, 확신은 중간이다.

엔비디아에는 단기 중립 내지 소폭 호재다. Rubin의 Azure 가동, MAI 학습 인프라, Bing, Azure Local 엣지까지 마이크로소프트의 스택 전반에 남아 있다. 중장기 위험은 Maia 300의 '와트당 토큰 +40%'가 실제 배치로 이어지는 경우다. 마이크로소프트에는 자체 칩이 엔비디아와의 가격 협상 카드다. 다만 이번 자료만으로는 카드의 크기를 알 수 없다.

이 주장이 틀리는 경우: 마이크로소프트가 Maia 200 물량을 공개하지 않았을 뿐 이미 상당량을 배치했을 수 있다. 보도는 Maia 200이 '가장 큰 모델들을 프로덕션에서 돌린다'고 적었다(s12). 반대로 엔비디아 쪽 자료(s3)는 엔비디아가 낸 보도자료라 자사에 유리한 사례를 골랐을 수 있다. Vera Rubin의 Azure 규모도 수치가 없다.
