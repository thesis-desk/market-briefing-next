20VC 대담(Matt Murphy·Jason Lemkin) : 앤트로픽 상장과 젠슨 복귀, 2021년 SaaS의 값

해석 앤트로픽 상장으로 '압도적 1위만 큰돈이 된다'는 전제가 굳어지면서, 4위 코딩 에이전트의 750억 달러 몸값과 성장 없는 2021년 SaaS(매출 2배 안팎)가 같은 잣대로 냉정하게 재평가되고 있다. 출연자들의 공통 결론은 보안·데이터 신뢰층(Databricks)과 에이전트 친화 플랫폼은 수혜, 사람이 쓰는 마케팅 자동화와 보안 인력이 없는 구형 SaaS는 피해라는 것이다. 다만 대부분 이해관계자의 구두 주장이라 확신은 중간 이하다.

사실
  • 앤트로픽이 주당 83달러에 사상 최대 규모 IPO를 했고(진행자는 '1조 달러 IPO'로 표현), 초기 투자자인 Menlo Ventures의 Matt Murphy는 구글이 15년 걸린 100억→1,000억 달러 성장을 앤트로픽은 1년 만에 하고 있다고 말했다.
  • 젠슨 황의 복귀 소식이 나온 이번 주 월요일 엔비디아 시가총액이 약 1조 달러 늘었고(진행자), Jason Lemkin은 그가 제품에 집중하고 대외 행보는 위축돼 벤처에는 소폭 악재라고 봤다.
  • Cognition은 두어 달 전 480억 달러에서 750억 달러 가치로 20억 달러 이상을 조달 중이며 매출은 20억 달러에 가깝다(진행자). 두 투자자 모두 이 가격에서 10배 수익 경로를 보지 못한다고 했다.
  • Bending Spoons가 Mailchimp를 36.8억 달러에 샀고(인튜이트의 인수가는 120억 달러), Lemkin은 상위 4분위 성장을 못 하는 2021년 SaaS 투자는 매출 2배 넘는 값을 받기 어렵다고 주장했다(Mailchimp 2.9배, Miro·Airtable 2배대).
  • CrowdStrike가 Zscaler를 439억 달러 전액 주식으로 인수하기로 했고(당일 CrowdStrike -9.6%, Zscaler +13%), Lemkin은 2027년 보안 감사에서 구형 B2B 앱 대부분이 떨어지고 바이브 코딩 앱도 신뢰를 잃을 것이라고 봤다.

설명

20VC의 주간 토론 회차다. 고정 패널 Rory O'Driscoll 대신 앤트로픽 초기 투자자인 Matt Murphy가 앤트로픽 상장 주간에 나왔다는 점이 이 회차의 가치다. 상장한 회사 내부 분위기와 Menlo의 보유 의지를 투자자 본인의 입으로 들을 수 있다.

설명

대화에서 알 수 있는 경위만 적는다. 젠슨 황은 뉴욕타임스·월스트리트저널의 스파이 의혹 보도와 사내 부하 직원과의 관계 문제가 겹친 가운데, 미국 정부가 움직일 수 있다고 우려한 이사회에 의해 사임했다가 이번 주 월요일 복귀했다. 출연자들은 행정부가 복귀를 도왔고 조사는 앞으로 이어질 것이라고 말한다. 경위의 세부는 출연자 발언에만 근거하며 원문 밖에서 확인하지 않았다.

  • 에이전트가 소프트웨어 구매자가 되고 있다(확신 중간 이하). Lemkin의 사용 경험(Muse·10K·Bill)이 반복해서 가리키는 기준은 API 품질, 가격, 안정성, 보안이다. 에이전트는 이 조건이 맞으면 떠나지 않고 어긋나면 즉시 떠난다. 사람의 화면 사용에 과금하던 범주(마케팅 자동화, 좁은 SMB CRM)는 신규 유입부터 잃고, 에이전트가 붙기 좋은 시스템(결제·지출, 데이터 플랫폼)은 오히려 끈적해진다. 이 주장의 근거는 주로 한 사람의 경험이고, 시장 수치로 뒷받침되지 않았다.
  • 보안과 데이터 통제가 2027년 구매 조건이 된다(확신 중간). 보안 사고 사례, 중국 모델 배제, 제로 데이터 보존 검증 요구가 한 방향을 가리킨다. 보안 운영 인력을 줄인 2021년형 SaaS와 바이브 코딩 앱은 감사에서 탈락할 위험이 있고, 검증 가능한 통제층(Databricks)과 플랫폼으로 통합한 보안 벤더(CrowdStrike+Zscaler)는 수혜 쪽이다.
  • 답해지지 않은 것: 앤트로픽 상장 직후 며칠간 공모가 부근에서 오르내리며 밀린 흐름이 어디서 멈추는지, 모델 우위가 뒤집힐 때의 하방, 젠슨 복귀 후 엔비디아의 대외 투자 규모, HubSpot 신규 고객 감소 수치의 사실 여부. 출연자 다수가 해당 종목의 이해관계자이고 수치 대부분이 구두라는 점이 이 대담 전체의 한계다.
