Microsoft 3Q26 실적발표 : 좌석에서 사용량으로, 1,900억 달러짜리 공급 제약

해석 Azure(고정환율 39%)와 M365 Commercial Cloud(고정환율 15%)가 직전 분기 가이던스를 넘었고, M365 Copilot 유료 좌석은 2,000만 이상으로 늘었습니다. 다만 회사는 공급 제약이 최소 2026년 내내 이어진다고 보고, 부품 가격 상승분 250억 달러를 포함해 2026 역년 CapEx를 약 1,900억 달러로 제시했습니다. 성장의 질은 좋아졌고, 남은 질문은 마진(Microsoft Cloud 매출총이익률 4Q 약 64%)과 현금흐름이 이 투자 속도를 따라오느냐입니다.

한 문장 결론

해석

매출 829억 달러(+18%)와 Azure 고정환율 39%로 직전 분기 가이던스를 모두 넘었지만, 이번 분기의 핵심은 숫자보다 사업 모델과 투자 규모의 재설정입니다.

  • 과금 모델 전환을 공식화했습니다. 경영진은 좌석당 사업(생산성·코딩·보안)이 모두 ‘좌석+사용량’ 사업이 된다고 말했고, GitHub Copilot을 6월 1일부터 사용량 기반으로 바꿉니다. Dynamics에서는 이 전환 때문에 갱신이 약해져 예약 성장이 둔화됐습니다.
  • Copilot이 변곡점을 넘은 신호가 나왔습니다. 유료 좌석이 1,500만(2Q)에서 2,000만 이상으로 늘었고, 좌석 순증은 전년 대비 +250%로 출시 이후 최고입니다. M365 Commercial Cloud는 고정환율 +15%로 가이던스(13~14%)를 넘었습니다.
  • 투자 규모가 역년 연간 숫자로 나왔습니다. 2026 역년 CapEx는 약 1,900억 달러이고 그중 약 250억 달러가 부품 가격 상승분입니다. 4Q CapEx는 400억 달러 이상이며, 공급 제약은 최소 2026년 내내 이어진다고 봅니다. 4Q Microsoft Cloud 매출총이익률 가이던스는 약 64%로 내려갑니다(3Q 66%).
원문

Amy Hood · CFO

이런 추가 투자와 GPU·CPU·스토리지 용량을 더 빨리 가동하려는 지속적인 노력에도, 우리는 최소 2026년 내내 (공급) 제약 상태가 이어질 것으로 예상한다.

해석
  • 마진은 구조적으로 내려가는 중입니다. Microsoft Cloud 매출총이익률은 67% → 66% → 4Q 약 64%로 이어지고, 4Q 회사 매출총이익률 함축치도 약 66%로 68%에서 내려옵니다. IC 영업이익률은 42% → 40%입니다. 원인으로 꼽은 AI 투자와 GitHub Copilot 사용 증가는 일시적 요인이 아니므로 구조적 압력으로 봅니다. 상쇄 요인은 GitHub 과금 전환(6월 1일)과 자체 칩·모델의 효율입니다.

해석

  • OpenAI 조정 지표입니다. EPS(4.27달러)와 영업외손익(9.61억 달러)은 OpenAI 투자 영향을 조정한 값이고, 전사본에 GAAP 값과의 차이는 나오지 않습니다. 야후의 실제 EPS도 4.27달러로 조정 기준과 같습니다.
  • 정의되지 않은 숫자가 있습니다. ‘AI 사업 연환산 매출 370억 달러’, ‘수요 신호’, ‘주간 참여도가 Outlook과 같은 수준’은 산식이나 기준이 없습니다. Copilot 사용 지표도 대부분 배수와 증가율로만 제시됐습니다.
  • 같은 이름이지만 기준이 다른 숫자가 있습니다. CapEx(319억 달러)는 금융리스를 포함하고, FCF는 유형자산 현금 지출(309억 달러)로 계산됩니다. 금융리스로 들인 데이터센터는 FCF에 바로 잡히지 않고 이자비용(4Q 영업외손익 약 −1억 달러의 원인)과 리스 지급으로 나중에 나타납니다. 4Q CapEx 가이던스도 금융리스 개시 시점에 따라 흔들립니다.
  • 가이던스 기준이 섞여 있습니다. Azure는 고정환율, IC·회사 매출은 달러 기준입니다. M365 Commercial Cloud 4Q는 조정(+15~16%)과 보고(+13~14%)가 따로 있습니다. FY26 영업이익률 ‘약 1%p 상승’은 일회성 비용을 포함한 값입니다.
  • 확정 계약과 전망을 구분해야 합니다. ‘인도해야 할 매출 6,000억 달러 이상’은 RPO 6,270억 달러를 가리키는 표현이고, OpenAI 몫이 포함돼 있습니다. ‘2년 만에 규모 2배’, ‘하반기 Azure 완만한 가속’, ‘FY27 두 자릿수 성장’은 전망입니다. 4분기 Azure 가이던스는 ‘높은 전년 기저’를 함께 강조했습니다.
  • 화자의 이해관계가 있습니다. CapEx 질문(Q&A 2·4)에서 경영진은 단기 자산과 매출의 연동, RPO 잔고, 모델 역량의 기하급수적 향상을 들어 투자를 정당화했습니다. 투자 회수 시점이나 수익률 수치는 제시하지 않았습니다.
  • 용량 기준이 불명입니다. ‘1GW 추가’는 회사가 IT·수전 기준을 밝히지 않았습니다.
  • 직접 답하지 않은 질문이 있습니다. 좌석·사용량의 장기 구성, 교체·자체 서비스 CapEx 규모, 파트너 활용과 배분 틀, Copilot에서 통하지 않은 것과 E7, OpenAI 계약의 수치 영향입니다(질의응답 절의 view 참조).
