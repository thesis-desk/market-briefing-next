Unity Software 4Q25 실적발표 : Vector가 Grow를 끌기 시작, Create 2년여 만의 최고 성장

해석 4Q25는 가이던스 상단을 넘었습니다. Vector가 3분기 연속 전분기 대비 10%대 중반 성장해 Grow 비중 56%가 됐고, 회사는 2026년 말 Vector 연 10억달러 이상 런레이트를 제시했습니다. 다만 1Q26 가이던스를 풀면 비Vector Grow와 Create가 전분기보다 크게 줄어드는 계절 저점이 함축돼 있고, 조정 EBITDA 마진(2025년 22%)과 SBC 비중(21%)이 거의 같아 GAAP 이익 체력은 아직 얇습니다.

한 문장 결론

해석

광고(Grow)의 축이 ironSource에서 Vector로 넘어가는 분기였습니다. Vector가 3분기 연속 전분기 대비 10%대 중반 성장해 Grow 매출이 전년 대비 11% 늘었고, Create도 비전략 매출을 빼면 16% 성장해 두 부문이 함께 가속했습니다. 조정 EBITDA 마진은 25%로 전년·전분기 대비 각각 200bp 올랐습니다.

  • Vector가 Grow 매출의 56%(2분기 전 49%)가 됐고, 회사가 2026년 말 Vector의 분기 매출 런레이트를 연 10억달러 이상으로 제시했습니다. ironSource 광고 네트워크는 1Q26 총매출의 6% 미만으로 줄어듭니다.
  • Create는 보고 기준 +8%, 비전략 매출 제외 +16%로 2년여 만에 가장 빠른 성장을 기록했습니다. 성장 동력은 구독 갱신과 가격 인상이고, 중국 Create는 연간 50% 가까이 늘었습니다.
  • 런타임 데이터의 Vector 반영(2Q26), 3월 GDC의 Unity AI 베타, 다음 주 인앱 결제 얼리 액세스(2Q GA), 브라우저 기반 협업 등 2026년 제품 일정이 이번 콜에서 제시됐습니다.

한눈에 이해하기

설명
  • 매출은 두 부문입니다. Grow는 광고 사업으로 AI 광고 플랫폼 Vector, 축소 중인 ironSource 광고 네트워크, 그 밖의 Grow 사업으로 나뉩니다(그 밖의 사업 구성은 원문에 없음). Create는 엔진·저작 도구의 구독 매출과 게임 밖 산업용(자동차 계기판 등) 매출입니다. 4Q25 기준 Grow가 Create의 두 배 규모입니다.
  • Vector는 회사가 'AI 플랫폼 매출'로 부르는 광고 모델입니다. 경쟁 축으로 내세우는 것은 모델 자체보다 신호의 질입니다. 엔진 런타임에서 나오는 게임 안 행동 데이터(진행·참여·가치를 느끼는 지점)를 클릭 데이터 위에 얹는다는 구상입니다.
  • Runtime Engine Data / Developer Data Framework(DDF): 개발자 옵트인으로 게임 런타임의 행동 데이터를 수집하는 장치입니다. 2025년 8월 출시돼 Unity 6.2로 만든 새 게임부터 수집했고, 구버전 게임용 셀프서비스도 나왔습니다. Vector 모델 반영은 2Q26 예정입니다.
  • ironSource 광고 네트워크: 회사가 레거시 사업이라 부르는 광고 네트워크입니다. 회사는 범용화된 저마진 매출로 보고 Vector로 대체되는 과정이라고 설명합니다.
  • 비전략(non-strategic) 매출: 회사가 정의를 밝히지 않은 분류입니다. 4Q24 Create에 1,000만달러가 있었고, 2026년 Create 가이던스는 비전략 매출과 일회성 항목 약 4,000만달러를 빼고 말합니다. 보고 성장률과 회사가 강조하는 성장률이 이 항목 때문에 갈립니다.
  • Create의 과금 구조: 활성 크리에이터의 약 90%는 Unity 6를 무료로 쓰고, 게임이 성공한 고객이 돈을 냅니다. 회사 스스로 '엔진에 과금하지만 실은 광고·커머스를 위해 더 많은 사람이 엔진을 쓰길 원한다'는 긴장을 인정하고, 좌석 기반 모델을 고집하지 않겠다고 밝혔습니다.
사실
  • 4Q25 Grow 매출 3.38억달러, Create 매출 1.65억달러.
  • 4Q25 Vector는 Grow 매출의 56%, ironSource 광고 네트워크는 11%.
  • 활성 크리에이터의 약 90%는 Unity 6를 무료로 사용.
  • 매달 약 35억 명 이상이 Made with Unity 게임을 이용.
  • DDF 옵트인율 90% 초과.

원문

Matthew Bromberg · CEO

올해 1월은 Vector 사상 최고의 매출 월이었습니다. 12월에 세운 연말 성수기 기록보다도 컸고, 작년 1월보다 72% 컸습니다.

2025년 내내, 그리고 2026년 1분기까지 ironSource 광고 네트워크의 급격한 감소가 때때로 Vector의 놀라운 성장을 가려 왔습니다. 그러나 그 흐름은 빠르게 끝나 가고 있고, 앞으로 몇 년간 광고 사업 전체의 성장률과 수익성을 크게 높일 것입니다.

이것은 단지 매출의 이동이 아니라 질의 이동입니다. 범용화된 저마진 광고 네트워크 매출을 깊이 차별화된 AI 플랫폼 매출로 대체하고 있습니다.

Unity 엔진은 에셋 생성기가 아니며, 한 번도 그런 적이 없습니다. 에셋은 언제나 대체로 우리 소프트웨어 밖에서 만들어져 왔습니다.

런타임 데이터를 넣는다고 번개가 치는 듯한 순간이 오리라고는 예상하지 않습니다. 대신 고도로 차별화된 행동 데이터가 더해지면 시간이 지나며 모델이 상당히, 복리로 개선될 것이라고 확신합니다.

3월 Game Developer Conference에서 새로 업그레이드한 Unity AI의 베타를 공개합니다. 개발자가 자연어만으로 캐주얼 게임 전체를 만들어 낼 수 있고, 우리 플랫폼에 네이티브여서 프로토타입에서 완성품으로 옮겨 가기 쉽습니다.
