Together AI : Qwen3 TTS를 실시간 음성 에이전트용으로 문자 100만 개당 20달러에 제공

해석 새 모델의 성능 발표라기보다, Apache 2.0으로 공개된 Qwen 음성 모델을 Together AI가 지연을 줄인 서빙과 함께 판매하기 시작했다는 출시 공지다. 모델은 누구나 호스팅할 수 있으므로 차별점은 서빙 지연과 API 완성도뿐이다. 그 핵심 수치인 첫 음성 97ms는 최선값 하나만 공개됐고 측정 조건이 없어, 판단의 근거로 쓰기에는 약하다.

주장 한 줄

설명

글이 독자에게 설득하려는 것은 하나다. 오픈 음성 모델 Qwen3 TTS를 Together AI에서 쓰면, 실시간 대화가 가능한 지연(첫 음성 최소 97ms)으로 화자 하나를 감정과 언어를 바꿔 가며 쓸 수 있다.

개발자를 겨냥한 판매 공지이고 읽은 범위는 전문이다. 경쟁 제품 비교, 품질 벤치마크, 사용량 수치는 들어 있지 않다.

화자는 고정하고 말투만 자연어 지시로 바꾼다

사실
  • '누가 말하는가'(목소리)와 '어떻게 말하는가'(전달 방식)를 분리한 오픈 TTS 모델이다.
  • 프리셋 목소리는 9개다. 목소리는 그대로 둔 채 'excited and upbeat' 같은 짧은 자연어 지시로 어조와 감정만 바꾼다.
  • 데모에서는 같은 목소리(aiden)가 같은 문장을 신남·분노·실망의 세 가지 지시로 읽는다.
  • 지시를 바꿔도 감정과 어조만 달라지고 목소리의 정체성은 바뀌지 않는다(FAQ).

출처 1 · Tell it how to say the line / FAQs

  • 지시는 요청의 instructions 필드로 보낸다. Python SDK에서는 extra_body로 넘기며, 이 지시는 선택 항목이다.
  • 필드 이름을 잘못 쓰면 오류 없이 무시된다. 그래서 지시가 반영되지 않는 것처럼 보이면 철자부터 확인하라고 안내한다.

출처 1 · Generate speech

해석

글에 나오는 목소리는 프리셋 9개뿐이다. 자기 목소리를 복제하거나 커스텀 화자를 만드는 기능은 언급되지 않는다. 브랜드 고유 목소리가 필요한 기업 고객에게는 이것이 한계일 수 있다. 다만 글에 없는 기능을 없다고 단정할 수는 없으므로 확신은 낮다.

한 목소리로 10개 언어를 말하지만 최고 품질을 위해서는 모국어 사용을 권한다

사실
  • 프리셋 9개가 모두 10개 언어를 말한다: 중국어, 영어, 일본어, 한국어, 독일어, 프랑스어, 러시아어, 포르투갈어, 스페인어, 이탈리아어.
  • 입력 텍스트는 선택한 언어로 직접 넣어야 하며 번역은 해 주지 않는다. 데모의 4개 언어 클립도 따로 번역한 문장을 썼다.
  • 목소리마다 모국어가 있다. Qwen은 최고 품질을 위해 모국어로 쓰기를 권하고, Together AI는 프리셋을 정하기 전에 필요한 언어로 직접 들어 보라고 권한다.

해석

9개 중 5개가 중국어 화자다. 독일어·프랑스어·러시아어·포르투갈어·스페인어·이탈리아어를 모국어로 하는 목소리는 하나도 없다. Qwen이 최고 품질을 위해 모국어 사용을 권하는 만큼, '10개 언어 지원'이라고 해도 유럽 언어에서는 최고 품질을 기대하기 어려운 구성이다. 유럽 시장에서 이 모델을 쓰려면 실제 청취 평가가 먼저다. 확신은 중간이다.

첫 음성 97ms를 내세워 음성 에이전트를 겨냥한다

사실
  • 스트리밍하면 첫 음성이 최소 97ms('as little as')에 나온다. Together AI 추론팀이 실시간 음성용으로 서빙 스택을 조정했다고 밝힌다.
  • 전체 텍스트가 있으면 HTTP 스트리밍(stream=True, response_format=raw)을 쓴다. 서버 전송 이벤트로 base64 인코딩된 24kHz 16비트 모노 PCM 조각이 오며, 감정 지시도 그대로 적용된다.
  • LLM이 토큰 단위로 텍스트를 내놓는 경우에는 WebSocket을 쓴다. 텍스트를 append로 이어 보내고 입력이 끝나면 commit한다. 서버는 한 문장이 다 모여야 그 문장을 합성한다.
  • 서버리스 추론과 전용 엔드포인트에서 모두 쓸 수 있다.

출처 1 · Stream audio for a voice agent

해석

97ms는 최선값 하나다. 분포(p50·p95), 입력 길이, 하드웨어, 동시 요청 같은 측정 조건이 없다. 비교 대상도 없다.

WebSocket 경로에서는 문장 단위로 합성하므로 실제 체감 지연은 '첫 문장이 완성될 때까지 기다린 시간 + 합성 시간'이 된다. 97ms는 텍스트가 이미 준비된 HTTP 경로에서 나온 값으로 읽는 편이 안전하다. 음성 에이전트의 응답 지연을 정하는 쪽은 앞단 LLM의 첫 문장 생성 속도일 가능성이 크다.

명시된 제약: 형식·타임스탬프·가격

사실
  • 출력 형식은 wav, mp3, raw(PCM), mulaw이고 opus, aac, flac는 지원하지 않는다. 샘플레이트는 24000(기본)과 8000이다.
  • 단어 단위 타임스탬프(alignment=word)는 지원하지 않는다.
  • 서버리스 가격은 문자 100만 개당 20달러다. 전용 엔드포인트도 제공하지만 그 가격은 글에 없다.
  • VoiceFinder 도구에서 목소리마다 최대 500자의 자체 문장을 생성해 비교할 수 있고, 요청 코드도 Python·TypeScript·cURL로 받을 수 있다.
  • Qwen이 Qwen3 TTS 12Hz 1.7B를 Apache 2.0 라이선스로 공개했고 가중치는 Hugging Face에 있다.

출처 1 · Generate speech / Choose a voice in VoiceFinder / FAQs

해석

8kHz와 mulaw를 지원한다는 것은 전화망(콜센터) 음성 에이전트를 염두에 둔 구성으로 읽힌다. 이건 해석이다. 반대로 단어 타임스탬프가 없으면 자막 동기화, 립싱크, 말 끊기(barge-in) 처리처럼 정밀한 시간 정렬이 필요한 용도에는 쓰기 어렵다. opus를 지원하지 않는 것도 WebRTC 기반 브라우저 음성 앱에서는 변환 단계가 하나 더 붙는다는 뜻이다.

근거는 어디서 왔나

설명
  • 독자가 직접 검증할 수 있는 것: 가격, 지원 형식과 파라미터, 라이선스(Apache 2.0)와 가중치 공개 여부, VoiceFinder 청취 결과. 모두 문서와 도구로 바로 확인된다.
  • 판매사만 가진 근거: 첫 음성 97ms. 측정 방법을 밝히지 않았고, 자사 서빙 스택에서 잰 자기 측정값이다.
  • 모델 쪽 서술(목소리 설명, 모국어 권고)은 Qwen의 설명·권고로 표시돼 있지만 어느 문서에서 가져왔는지는 밝히지 않았다. 품질 비교나 벤치마크는 Qwen 것이든 Together AI 것이든 제시되지 않았다.

누가 득을 보고 누가 손해를 보는가

사실
  • 글이 직접 지목하는 수혜자는 실시간 음성 에이전트를 만드는 개발자와, 새 시장에 진출하면서 같은 목소리를 유지하려는 제품이다.
  • 특정 경쟁사나 경쟁 제품은 언급하지 않는다.

출처 1 · Summary / Keep one voice across 10 languages

해석

구조로 보면 이득은 Together AI에 간다. 오픈 모델을 서빙하는 대가로 사용량 과금 상품을 하나 더 갖게 된다. Qwen 쪽은 채택 저변이 넓어지지만, 이 글에서 Qwen에 돌아가는 직접 수익은 확인되지 않는다. 폐쇄형 TTS API 업체에는 가격 압력이 될 수 있다. 다만 글에 비교 가격이나 품질 자료가 없어 근거가 약하다.

비판적으로 다시 읽기

해석
  • 이해관계: 글쓴이가 곧 판매사다. 97ms, '실시간 대화가 가능한 속도' 같은 표현은 마케팅 문구이고, 독립 검증이 없다.
  • 주장이 성립하려면 두 전제가 필요하다. 하나는 Qwen3 TTS의 음질이 상용 수준이라는 것, 다른 하나는 97ms가 일반 부하에서도 재현된다는 것이다. 둘 다 글 안에서는 입증되지 않는다.
  • 빠진 반대 근거: 품질 벤치마크, 지연 분포, 전용 엔드포인트 가격, 목소리 복제 여부, 동시 처리 한도. 또한 모국어가 아닌 언어의 품질을 Qwen 스스로 유보하고 있다는 점이 '10개 언어'라는 헤드라인에 가려져 있다.
  • Apache 2.0이므로 같은 가중치를 다른 추론 업체나 고객이 직접 호스팅할 수 있다. 문자 100만 개당 20달러가 비싼지 싼지 판단할 기준은 글 안에 없다.

작성자의 생각

해석

동의하는 부분: 화자와 전달 방식을 분리한 설계, 그리고 HTTP와 WebSocket 두 경로로 스트리밍을 정리한 것은 음성 에이전트 개발자에게 실용적이다. 오류 없이 무시되는 필드명 같은 함정까지 적어 둔 것도 문서로서 성실하다.

다르게 보는 부분: 이 출시는 모델 경쟁력의 증거가 아니다. 오픈 모델을 서빙하는 업체들 사이의 제품군 경쟁으로 읽는 편이 맞다. 원문을 직접 읽을 가치는 API를 붙일 개발자에게만 있다. 투자 판단에 쓸 정보는 이 리포트에 담긴 수준이 전부다.

투자자 관점의 정리

해석
  • 확인된 것: 오픈 가중치 TTS가 '서빙 업체가 판매하는 기성 부품'이 됐다. Apache 2.0 모델에 사용량 과금을 붙이는 구조이므로 Together AI의 가치는 모델이 아니라 지연·통합·가격에서 나온다. 같은 가중치를 누구나 올릴 수 있어 가격 차별화 여지는 좁다. 확신은 중간이다.
  • 새로 나온 것: 문자 100만 개당 20달러라는 공개 가격과, 실시간 음성(8kHz·mulaw, WebSocket)을 겨냥한 구성이다. 음성 에이전트, 특히 전화망 시장으로 추론 수요가 넓어진다는 신호로 볼 수 있다. 다만 사용량 수치가 없어 규모는 알 수 없다. 확신은 낮다.
  • 답하지 않은 것: 지연 분포와 측정 조건, 전용 엔드포인트 가격, 품질 비교, 목소리 복제 기능, 채택 현황. 이 글로는 Together AI의 매출이나 마진 추정을 바꿀 근거가 없다.
  • 종목 판정: 원문에는 상장사도 주가·배수 자료도 없다. Together AI(비상장)에는 제품군 확대라는 점에서 약한 호재지만, 모델 차별성이 없어 강도는 낮다(확신 낮음). Qwen(모회사 포함)과 폐쇄형 TTS 업체에 대해서는 원문에 수익·경쟁 근거가 없으므로 판정하지 않는다.
  • 다음 확인 지점: 독립 측정한 TTS 첫 음성 지연(p50·p95), 같은 Qwen3 TTS 가중치를 서빙하는 다른 업체의 가격, 커스텀 또는 복제 목소리 지원 여부, 그리고 Together AI가 음성 사용량이나 매출 기여를 공개하는지. 다른 업체가 더 낮은 가격이나 비슷한 지연을 제시하면 위의 약한 호재 판정은 중립으로 바뀐다.
