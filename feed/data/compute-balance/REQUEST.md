# 요청

질문: 누가 AI 컴퓨팅을 얼마나 갖고 있고, 누가 얼마나 쓰며 얼마를 치르는가.

2026-11-19 대화에서 정한 내용이다.

## 무엇을 모으나

- 칩 설계사(엔비디아·AMD·브로드컴·미디어텍·마벨)와 보유자·수요자(오픈AI·앤트로픽·메타·구글·마이크로소프트·아마존·xAI, 그리고 오라클·코어위브 등 임대 사업자)의 공시와 실적 발표, Epoch AI 같은 조사기관의 추정.
- '소모'는 둘로 본다: 쓰는 용량(빌린 것 포함)과 그 가운데 훈련·추론·사내 사용의 몫, 그리고 돈(컴퓨트 지출).
- 중국·국부 펀드 쪽은 합계 한 줄로만 둔다.

## 완결의 기준

값을 나열하는 데서 끝내지 않고 서로 독립인 방향에서 센 값이 맞물리는지 본다. 남는 차이는 감추지 않고 '설명 안 되는 몫'으로 적는다.

1. 공급 = 보유 증가 — 설계사 매출에서 역산한 칩 전력 ↔ 보유자의 설비투자·가동 용량.
2. 보유 = 자기 사용 + 빌려준 것 — 클라우드·네오클라우드의 보유량 ↔ 연구소의 계약·사용량.
3. 사용 = 훈련 + 추론 — 연구소가 쓰는 용량 ↔ 컴퓨트 지출·매출.
4. 상한 — 부지별 전력, CoWoS·HBM 생산량.

공시는 달러로, 발표는 GW 로 말한다. 그래서 등식마다 달러 기준과 GW 기준을 나란히 맞추고, 둘을 잇는 단가(십억 달러/GW·년)를 계약마다 계산해 묶음 S4 에 둔다.

## 지난 조사에서 고칠 점

- 확인 안 된 값을 줄인다: 값은 공시·발표문을 열어 읽은 것만 적고, 보도로만 아는 값은 계산의 분모로 쓰더라도 그렇게 밝힌다.
- 전체 그림을 낸다: 묶음마다 '전체 가운데 얼마가 잡혔나'를 `STATUS.md` 에 적는다.

## 순서

0. 원천 점검(마침) → 1. 앤트로픽 S-1 과 달러↔GW 환산(마침, 여기서 멈춰 보고) → 2. 공급 → 3. 보유 → 4. 사용·소모(오픈AI·xAI·하이퍼스케일러) → 5. 맞추기 → 6. 컴퓨팅 배분표 반영과 리포트.

1단계 뒤로는 멈추지 않고 짧은 진행 보고만 하며 맞추기까지 잇는다.
