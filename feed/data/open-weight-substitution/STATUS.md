## 지금 어디까지 왔나

- 1차(직접 읽은 자료 32건)와 2차(바깥 자료 세 갈래에서 고른 69건)를 마쳤다. 기록은 101건이고 가설 셋은 모두 `판단 보류`다.
- 2차는 수집한 119건 가운데 인용문이 저장된 원문에 그대로 있는 것만, 방향과 이유를 다시 적어 올렸다. 검색 요약으로만 본 값과 출처가 약한 글(이름 없는 사례, 판매자의 자체 벤치마크)은 올리지 않았다.
- 남은 일은 3차다 — 무게가 큰 값의 원문을 다시 확인하고 가설을 판정한다.

## 지금까지 보인 것 (AI 의 해석, 판정 아님)

**H1(가져가는 곳은 소형 클로즈드다) — 처음 생각보다 약하다.**

- 맞는 쪽: Menlo 의 계층별 몫(소형 클로즈드의 토큰 29% → 13%, 프론티어의 지출 35% → 63%), Vercel 에서도 토큰 1위는 DeepSeek 이고 지출의 절반 넘게는 Anthropic, Ramp 에서 오픈 모델 플랫폼을 쓰는 기업의 96.4%가 OpenAI·Anthropic 을 함께 쓴다, Anthropic 상장 서류가 내줄 수 있는 범위를 "비용 효율을 지능보다 앞세우는 일감"으로 적었다.
- 어긋나는 쪽: 최상위 모델이 하던 에이전트 일을 통째로 옮긴 사례가 여럿이다. Cursor 는 Kimi K2.5 위에 올린 Composer 2.5 로 코딩 에이전트 지수 62점(Opus 4.7 max 66점)을 과제당 0.07~0.44달러(4.10달러)에 냈고 이것은 제3자(Artificial Analysis)가 쟀다. Unblocked 는 Opus 에서 GLM 5.2 로, Lindy 는 Claude 에서 DeepSeek 으로 옮겼다. Uber 의 코드 리뷰에서는 가장 비싼 오픈웨이트가 가장 싼 프론티어보다 쌌다.
- 가격도 소형에서 멈추지 않았다. OpenAI 는 7월에 Luna 만 80% 내렸지만 9월에는 Sol 도 절반으로 내렸고, Anthropic 은 Opus 5.5 를 20% 낮게 냈으며 Sonnet 5 의 예고한 인상을 취소했다.
- 반대로 소형 클로즈드가 물량을 되찾은 값도 있다. 값을 내린 Luna 가 OpenRouter 에서 OpenAI·Anthropic 합산 토큰의 47%를 가져갔고, Ramp 는 프론티어에서 빠진 물량의 대부분이 더 싼 클로즈드로 갔다고 적었다.

**H2(사후 학습한 오픈웨이트는 같은 품질을 몇 분의 1 비용으로 낸다) — 사례는 많고 거의 다 자기 보고다.**

- 맞는 쪽: Harvey Review Table(Fable 5 보다 높은 점수, Sonnet 5 보다 셀당 54.8% 쌈), Intercom(답변 모델을 Sonnet 4.0 에서 자체 모델로 전량 교체), Pinterest(거래당 비용이 비슷한 클로즈드의 8% 미만), Cursor(위와 같다).
- 걸리는 쪽: Unblocked 는 토큰 단가로는 95% 절감을 기대했지만 과제당으로는 68%였고 품질은 프론티어가 낫다고 적었다. Harvey Tenet 은 긴 법률 과제에서 기반 모델보다 비용이 내리지 않았다. a16z 설문은 대기업이 미세조정에서 멀어지고 총소유비용이 가까워진다고 적었다. Decagon 은 최전선이 움직일 때마다 새로 학습한다고 했다.
- 칼럼의 둘째 고리("싼 것은 토큰이지 일이 아니다")에 대해: 토큰 단가의 차이가 과제당으로는 줄어든다는 점은 Unblocked 의 값(95% → 68%)이 받친다. 그러나 줄어들 뿐 뒤집히지는 않았다.

**H3(그 지출이 프론티어 랩의 매출을 깎을 크기로 커진다) — 증가율과 크기가 갈린다.**

- 커지는 쪽: OpenRouter 에서 클로즈드의 지출 몫이 89%(1월 첫 주) → 73%(9월 둘째 주)로 내렸다. 플랫폼들의 매출이 빠르게 는다(Fireworks 10억 달러(7월) → 15억 달러(9월), Baseten 1년에 20배, Applied Compute 1억 달러 초과). OpenAI 는 셀프서비스 미세조정을 접고 있다.
- 작은 쪽: Menlo 의 오픈소스 지출 몫 4%(1년 전 6%), a16z 설문을 인용한 11%(1년 전 19%), Ramp 의 채택률 6.4%(1월 4.5%). Fireworks 의 분기 환산 매출은 Anthropic 3분기 매출의 2.2%다. 플랫폼의 매출총이익률은 약 45~50%로 추정되고 Together 매출의 30~40%만 토큰 API 다.
- 중국 기반 모델을 쓰지 않는 곳: AT&T(오픈 모델로 40%를 돌리지만 중국 모델은 쓰지 않는다), Unblocked 의 규제 고객, Mistral 대표가 말한 방산·금융.

## 칼럼과 어긋나는 값

칼럼은 그대로 두기로 했다(요청자 결정). 후속편에서 다뤄야 할 어긋남만 적는다.

- **첫째 고리(돈은 넘어가지 않았다)**: OpenRouter 자체 자료에서 오픈웨이트의 지출 몫은 여덟 달에 11% → 27%로 올랐다(`tiers.json` 의 `openrouter-closed-spend-share`). 수준으로는 칼럼의 말이 맞지만 방향은 칼럼이 "틀리게 되는 조건" 첫째로 든 쪽으로 움직여 왔다.
- **둘째 고리(같은 점수대에서는 클로즈드가 더 싸다)**: 범용 오픈웨이트를 공개 API 가격으로 쓴 값이다. 오픈웨이트 위에 올린 특화 모델(Cursor Composer 2.5)은 같은 곳(Artificial Analysis)의 코딩 에이전트 지수에서 프론티어의 10분의 1 아래 비용을 냈다. 다만 2026-05 의 값이고 오늘 받은 지수 목록에는 Composer 가 없다.
- 오픈웨이트 위에 올린 특화 모델은 가중치를 공개하지 않으므로 순위표에서는 "클로즈드"로 잡힌다. 오픈웨이트·클로즈드로 나눈 집계는 이 쓰임을 보지 못한다.

## 판단하기 어려웠던 것

- 오픈소스의 지출 몫이 출처마다 다르다. Menlo 4%(기업), a16z 설문 인용 11%(대기업 100곳), OpenRouter 27%(개발자·스타트업 채널). 표본이 다르고 방향도 다르다(앞의 둘은 내렸고 OpenRouter 는 올랐다).
- 사후 학습 채택도 갈린다. Menlo 는 6% → 10%로 늘었다고 했고 a16z 설문은 대기업이 미세조정에서 멀어졌다고 했다. 스타트업과 대기업이 다르게 움직일 가능성이 있다.
- Fireworks 의 맞춤 비중은 회사 글(7월, "고객 데이터로 특화한 모델 95% 이상")과 대표의 발언(11월, "맞춤 모델 또는 맞춤 배포 80% 이상")이 다르다.
- 사례의 비용 절감은 견준 대상이 제각각이다(기반 모델, 중간 등급 클로즈드, 최상위 프론티어). 기록의 `basis` 에 적었지만 한 줄로 합칠 수 없다.
- Anthropic 의 가격 인하 영향(분기 6억 달러)은 새 모델 버전의 가격 인하와 계약 할인을 합친 값이고, 오픈웨이트 때문이라는 설명은 서류에 없다.

## 못 찾은 것

- 프론티어 랩의 계층별(최상위·소형) 매출과 기업 API 만의 매출.

- 특화 모델의 비용·품질을 제3자가 잰 값(Cursor 한 건뿐이다). Composer 의 지금 지수 값.

- 미세조정·강화 미세조정 상품의 가격과 도입 건수, 추론 플랫폼의 고객 집중도.
