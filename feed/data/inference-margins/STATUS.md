## 지금까지 보인 것 (AI 의 해석, 판정 아님)

**H1(토큰 재판매는 범용품이라 마진이 얇다) — 값은 정가에 묶여 있고, 마진은 칩 세대가 가른다.**

- 값이 무너지지 않는 쪽: 같은 모델을 파는 사업자들이 가장 많이 붙이는 값은 개발사 직판가다(Kimi K3.1 Pro 엔드포인트 28개 중 10개가 10달러, GLM 5.3 은 47개 중 15개가 4.40달러). Fireworks·Together·Baseten 은 자기 가격표에서도 같은 값을 쓴다. GLM 5.2 는 후속 모델이 나온 뒤 넉 달 동안 정가가 그대로였다. 최저가 엔드포인트가 가져가는 물량은 대부분 1% 안팎이고, 하이퍼스케일러는 정가보다 비싸게 걸어 둔다.
- 값이 무너지는 쪽: 후속 모델이 나오면 옛 모델의 정가가 풀린다(Kimi K2.6 출력 중앙값 −15%, 미국 대형 사업자 이탈). 물량이 많은 DeepSeek V4.1 Flash·GLM 5.3 은 물량이 싼 사업자로 기운다(GLM 5.3 의 요청 수 가중 단가 2.73달러 대 중앙값 4.20달러, 30분 표본 하나). 오픈웨이트의 유효 단가는 1월 → 10월 −70%(구성 변화 포함). 토큰 API 를 접거나 팔린 곳이 여럿이다(Lambda, OctoAI, Groq 의 GPU 임대 전환, Replicate, Moondream). GroqCloud 는 2025년 비용이 매출의 1.6배였다(추정).
- 원가: 같은 DeepSeek R1(8k/1k, 사용자당 초당 50토큰)의 100만 토큰당 원가가 H100 2.19달러, H200 0.28달러, B200 0.065달러다(InferenceX, 비공식 사본). 최신 랙에서는 원가가 개발사 정가보다 크게 낮다. DeepSeek 은 자기 서빙의 이론 이익률을 원가의 545%로 밝혔다(2025-02). 네오클라우드 GPU 임대가는 올해 42~54% 올랐다.
- 그래서: 토큰 재판매 전체가 얇다기보다, 최신 랙을 높은 가동률로 굴리는 쪽은 개발사 정가 아래에서도 남기고 옛 칩을 빌려 쓰는 쪽은 남기기 어렵다는 쪽으로 기운다.

**H2(돈은 사후 학습·전용 배포에 남는다) — 매출은 그쪽에 있고, 웃돈은 사업자마다 다르다.**

- 맞는 쪽: Fireworks 트래픽의 80% 이상이 맞춤 모델·맞춤 배포다. 전용 배포 H100 시간당 정가가 Fireworks 8.00 · Baseten 6.50 · Together 5.49달러로 GPU 임대 시세(Together 클러스터 3.45~3.99달러)의 1.4~2.3배다. Nebius 는 토큰 API 를 입구로 전용 인프라로 넘기고, CoreWeave 는 관리형 추론을 "프리미엄 상품"으로 부른다. Bedrock 에서 미세조정한 모델의 추론 단가는 기본 모델보다 약 30% 높다.
- 걸리는 쪽: DeepInfra 는 전용 배포 H100 을 2.90달러에 팔고, Together 는 최신 칩(H200·B200·B300)의 전용 추론 정가를 클러스터 임대가와 같게 둔다 — 웃돈은 경쟁이 붙으면 줄어든다. 전용 용량 매출이 소수 고객에 몰려 있다(Crusoe 관리형 추론 수주의 최대 65%가 한 고객, Cerebras 분기 매출의 72%가 두 고객 — 검색 요약). Cerebras 클라우드 부문 GAAP 매출총이익률은 24.3%다. OpenAI 는 "미세조정이 필요한 사용 사례가 줄었다"며 셀프서비스 미세조정을 접는다.

**H3(하이퍼스케일러가 독립 사업자의 자리를 좁힌다) — 들어오지만 값으로 밀어내지 않고, 독립 사업자를 유통에 들였다.**

- 맞는 쪽: Bedrock·Vertex·Azure 가 최신 중국 모델을 관리형으로 올렸다(Bedrock Kimi K3 9/18, GLM 5.3 10/5). Microsoft 는 Foundry 의 오픈소스 모델 매출이 10배라고 했고, AWS 는 Bedrock 토큰 물량 17배를 말했다. 하이퍼스케일러도 미세조정과 전용 용량(Custom Model Import, Provisioned Throughput, Managed Compute)을 판다.
- 반대 쪽: 하이퍼스케일러의 단가는 개발사 정가와 같거나 비싸다. Azure Foundry 는 Fireworks 의 모델을 "FW" 판으로 되팔고(Kimi K3 는 Microsoft 자체판 없이 FW 판만), 사용량을 Azure 약정에서 차감한다. Fireworks 는 AWS Marketplace 에서 연 50만 달러 약정을 팔고, Baseten 은 AWS 와 공동 판매 계약을 맺었다. 독립 사업자는 계속 빨리 큰다(DeepInfra 연환산 1.05억 달러로 1년 14배, Together·Fireworks 10억 달러 초과). ## 판단하기 어려웠던 것

- 사업자 간 최고/최저 단가 배수는 판촉 할인을 넣느냐에 따라 몇 배씩 달라진다(DeepSeek V4.1 Flash 정가 기준 30배, 할인 반영 180배). 그래서 배수 기록은 넣지 않고 정가 중앙값·최빈값·개발사 직판가를 쓴다.
- InferenceX 의 100만 토큰당 원가는 분모에 캐시 재사용 입력이 들어간 전체 토큰이고 사용자당 속도 조건에 따라 몇 배씩 달라진다. 화면마다 값이 어긋나고 칩마다 측정일이 달라 세대 차이와 소프트웨어 개선이 섞여 있다. 출력 단가와 바로 견주지 않는다.
- 오픈웨이트 유효 단가 −70% 와 GPU 임대가 +42~54% 의 대비는 같은 모델·같은 칩을 견준 것이 아니다. 칩당 처리량 개선(엔비디아는 소프트웨어만으로 한 달에 최대 5배를 주장)이 차이를 메울 수 있어 방향을 '양쪽'으로 적었다.
- "전용 용량"이 맨 GPU 임대인지 관리형 전용 배포인지에 따라 H2 의 방향이 갈린다. 토큰 API 를 접고 GPU 임대로 옮긴 사례(Groq, Lambda)는 H1 지지, H2 양쪽으로 적었다.
