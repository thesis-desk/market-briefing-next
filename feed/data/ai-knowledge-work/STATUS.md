# 진행 상태

질문: AI 는 코딩을 넘어 범용 지식노동으로 번지는가 — 성장 여지는 얼마나 남았고, 지금의 투자는 회수되는가.
묶음별 진행, 못 모은 것, 출처끼리 달랐던 것, 판단하기 어려웠던 것을 적는다. 값을 고치면 여기에 적는다.

## 첫 훑기에서 보인 것 (AI 의 해석)

- **넓이는 느리게, 깊이는 빠르게 는다.** 업무시간 중 AI 보조 비중은 4.1% → 6.3% 로 2.2%p 올랐는데(`us-genai-work-hours-assisted`) Anthropic 의 9개월 매출은 전년 동기의 13배다(`anthropic-revenue`). 지출이 좁은 층에 몰려 있다 — 10만 달러 이상 고객이 매출의 74%다(`anthropic-100k-customers`).
- **역량은 코딩 밖 납품물까지 올라왔다.** 프리랜서 프로젝트 자동화율이 13개월에 2.5% → 41.25% 다(`rli-automation-rate`).
- **코딩 밖에서 깊이가 생겼다는 기록은 아직 없다.** 코딩 도구를 쓰지 않는 기업 사용자의 지출은 월 75달러 미만이고 다량 사용자의 20분의 1 이하다(`anthropic-enterprise-user-spend`). Claude 가 닿은 직업의 폭은 직전 보고서와 거의 같다(`claude-jobs-quarter-tasks`).
- **두 랩의 연환산 매출은 지식노동 임금 풀의 0.33~0.81% 다**(`two-lab-run-rate-share-of-wage-pool`). 투자가 요구하는 매출은 5~11% 다(`required-revenue-share-of-wage-pool`).

그래서 다음에 채울 것은 고리 `spread` 를 직접 재는 기록이다.

## 못 모은 것 (다음에 모을 것)

### K1 역량

- GDPval 의 그 뒤 값. OpenAI 페이지는 curl 로 열리지 않는다(브라우저로 연다). 검색 요약에 GPT-5.4 82% 가 있으나 원문 미확인.
- RLI 의 중간 시점. 순위표에 모델별 평가 날짜가 없어 시계열이 두 점뿐이다. 검색 요약에는 2026-07 Fable 5 가 15.8%(순위표의 15.83 과 맞는다)라는 값이 있다.
- 컴퓨터 사용(OSWorld 등)과 직무별 벤치마크, METR 의 2026-04 뒤 모델.

### K2 사용

- 센서스 BTOS 의 회차별 원자료(2026-10 회차 24.6% 는 2차 보도). 문항이 바뀐 2025-11 앞뒤를 따로 둔 시계열.
- 코딩 대 그 밖의 비중을 토큰·금액으로 잰 값. 데스크의 OpenRouter 수집(`desk market usage`)에 쓰임 분류가 있는지 확인.
- Microsoft 365 Copilot 좌석 수, ChatGPT 의 업무 사용 비중, Anthropic Economic Index 의 2026-03 뒤 보고서.
- 미국 밖의 사용 조사.

### K3 지출과 매출

- **직능별 지출 시계열**(Ramp AI Index 등 지출 관리 회사의 자료). 고리 `spread` 의 중심 자료다.
- **코딩 밖 전문 에이전트의 매출**(법무, 고객지원, 의료 기록, 재무).
- 코딩 도구의 매출(Claude Code, Cursor, GitHub Copilot)과 개발자 1인당 토큰 지출 대 인건비.
- OpenAI 의 연환산 매출 원문. 지금은 500억~700억 달러로 엇갈린다.
- 구글·마이크로소프트의 AI 매출 공시, 중국 랩.
- 토큰 가격을 내린 뒤 지출이 늘었는지(가격 탄력성)를 볼 자료.

### K4 노동시장

- **IT서비스·BPO 기업의 인력과 매출**(TCS, Infosys, Accenture, Teleperformance 등 분기 공시). 이미 과제 단위로 떼어 계약된 일이라 대체가 가장 먼저 숫자로 드러날 곳이다.

- 스탠퍼드 대시보드의 월별 값.

- MIT NANDA 보고서 원문(표본 수, '시범 사업'과 '효과'의 정의). 지금은 검색 요약만 봤고 신뢰도를 낮게 두었다.

## 출처끼리 달랐던 것

- **OpenAI 연환산 매출**: 2026-09 말 약 500억 달러(파이낸셜타임스 인용 보도)와 약 700억 달러(Axios). 둘 다 검색 요약이라 고르지 못했고 값은 비웠다(`openai-run-rate`).
- **고객지원 실험의 효과**: 초록은 15% 다. 14% 로 옮긴 글이 많다(앞선 판의 값으로 보인다 — 확인하지 못했다).
- **RLI 평가 건수**: 순위표 설명은 비공개 230건으로 채점한다고 적는데 값은 240건의 배수와 맞는다.

## 판단하기 어려웠던 것

- **방향(`sides`)을 정하는 기준.** 낮은 침투율은 H1 의 조건이면서 회의론의 근거다. 수준만 있는 기록은 `양쪽`, 같은 지표가 오르는 것이 확인되면 `지지`, 멈춘 것이 확인되면 `반박`으로 두었다.
- **회사가 낸 값의 무게.** Anthropic 의 고객 수·순매출유지율·사내 코드 비중은 원문을 읽었지만 회사 정의이고 감사 대상이 아니다. 감사받은 매출과 계약 금액만 `high`, 나머지는 `med` 로 두었다.
- **임금 풀을 천장으로 써도 되는가.** 임금 합은 넘어갈 수 있는 일의 상한이고 벤더 매출의 상한이 아니다. 계산 기록은 침투율을 가늠하는 용도로만 쓰고, 회수율 가정은 기록으로 만들지 않았다.
